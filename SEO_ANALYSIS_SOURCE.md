# Grove Media Creative - SEO Analysis Source Data

This document contains a comprehensive breakdown of the project "Grove Media Creative" for the purpose of SEO analysis and master prompt generation.

---

## 1. Project Overview
- **Brand Name**: Grove Media Creative
- **Official URL**: https://grovemediacreative.com.tr
- **Target Market**: Turkey (Localized for Istanbul and major cities).
- **Primary Language**: Turkish (tr-TR).
- **Core Value Proposition**: Specialized ad infrastructure (SGTM), high-performance web design (Next.js), and sector-specific digital marketing solutions with a focus on high ROAS.

---

## 2. Technology Stack & Performance
- **Framework**: Next.js 14+ (App Router).
- **Styling**: Tailwind CSS.
- **Performance Highlights**:
    - Ultra-fast page loads (Next.js Optimization).
    - Mobile-first responsive design.
    - Server-Side Tracking (SGTM) to bypass iOS 14+ and Ad-blocker data loss.
    - Google Tag Manager (GTM) & Meta Conversion API (CAPI) integration.
- **Fonts**: Bebas Neue (Headings), Inter (Body).

---

## 6. Technical SEO Details
- **Title Pattern**: `[Industry Name] İçin Web Sitesi | Grove Media Creative`
- **Meta Description Strategy**: Focuses on specific pain points (e.g., "Müşteri bulamama", "Boş geçen günler") and offers a technical solution.
- **Heading Hierarchy**:
    - `H1`: Industry title (e.g., "Tesisatçılar İçin Web Sitesi").
    - `H2`: "Neden Sektöre Özel Yaklaşım?", "Nasıl Çalışıyoruz?", "Sık Sorulan Sorular".
- **Schema.org Implementation**:
    - `Agency` JSON-LD on root.
    - `FAQPage` JSON-LD on services.
- **Canonical Tags**: Implemented on all primary routes.
- **Robots.txt**: Standard allow all, pointing to sitemap.
